# Downloadbestanden

Open het gewenste ZIP-bestand op GitHub en klik rechtsboven op **Download raw file** (de downloadpijl). Je moet eventueel aangemeld zijn bij GitHub om deze repository te lezen.

- `OPTIMAT-WordPress-Gravity-Forms-plugin.zip`: installeerbare connector voor de twee WordPress-sites met Gravity Forms.
- `OPTIMAT-Sales-Hub-broncode-en-hosting.zip`: volledige applicatiebroncode met handleidingen en hostingconfiguratie.

De bestanden bevatten geen klantdatabase, geheime configuratiewaarden of standaardaccount. Hosting en een publiek HTTPS-adres moeten nog worden geactiveerd; een GitHub-download maakt geen live CRM aan. Gebruik de bron-ID's uit de uiteindelijke productie-installatie bij de WordPress-configuratie.
